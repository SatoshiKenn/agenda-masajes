# Agenda de masajes

Para publicarla en GitHub Pages:

1. Crea un repositorio nuevo en GitHub (por ejemplo `agenda-masajes`).
2. Sube el archivo `index.html` ("Add file" → "Upload files").
3. Ve a Settings → Pages → Branch: `main`, carpeta `/ (root)` → Save.
4. En uno o dos minutos la agenda estará en `https://TU-USUARIO.github.io/agenda-masajes/`.

Las citas se guardan en el navegador de cada dispositivo. Usa "Crear enlace para otro dispositivo" para pasarlas a otro, y "Descargar respaldo" para guardar una copia.
